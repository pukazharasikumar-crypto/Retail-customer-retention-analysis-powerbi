# Retail-customer-retention-analysis-powerbi
Interactive sales analysis dashboard using Power BI
## Overview

This project is a Power BI Sales Dashboard used to analyze business performance and sales trends.
## Features

- KPI tracking
- Sales analysis
- Regional filtering
- Revenue insights
- Interactive dashboard
## Tools Used

- Power BI
- power query editor
- DAX
